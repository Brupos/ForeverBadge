# ForeverBadge (WoW: Forever)

**Support development on Ko-fi:** https://ko-fi.com/brupos

**ForeverBadge** is a lightweight, zero-bloat addon for **World of Warcraft: Forever** that automatically marks brand-new Forever content so you never miss new items, crafting recipes, vendors, or NPCs.

## Features
* **Compact Tooltip Tag:** Adds a clean `[Forever Exclusive]` badge to new items, recipes, vendors, and NPCs without bloating your tooltips.
* **Bag & Vendor Highlights:** Adds a glowing border and corner diamond marker to Forever-exclusive items inside your bags (supports both **Blizzard Bags** and **Baganator**) and merchant windows.
* **NPC Dialog Badges:** Displays a `[Forever]` tag on gossip and quest window titles when interacting with new Forever NPCs.
* **Customizable Highlight Color:** Type `/fb` (or `/fb color`) in-game to pick any highlight color or toggle individual features on/off.
* **Community Discovery Tools:** Includes `/fb inspect` and `/fb export` to help identify and export newly discovered Forever IDs.

## Download

## Slash Commands
* `/fb` — Open the Forever Badge settings panel
* `/fb color` — Open the custom highlight color picker
* `/fb inspect` — Print the NPC ID of your current target
* `/fb stats` — View how many new items and NPCs you have discovered
* `/fb export` — Open a copyable window of discovered IDs

## Manual Installation
1. Download the latest release ZIP from CurseForge, Wago Addons, or GitHub Releases.
2. Extract the folder into `World of Warcraft/_forever_/Interface/AddOns/`.
3. Make sure the folder is named **`ForeverBadge`** (remove `-main` if downloaded from GitHub source).
4. Restart the game or type `/reload` in chat.
